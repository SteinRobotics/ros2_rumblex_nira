# Nira simulation

Use `ros2 launch nira_gazebo test_gazebo_launch.py` for the composed mesh simulation.
Standalone `simulation_gazebo.launch.py`, `simulation_mesh.launch.py` and
`visualization_rviz.launch.py` are also available. All use Nira models and controllers.
See [launch commands](../README_LAUNCH.md) and [resource limits](../nira_doc/BUILD_AND_TEST.md).
